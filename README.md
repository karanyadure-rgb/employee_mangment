

## 📖 Overview
The Employee Management System is a lightweight, command-line application designed to simplify the tracking of employee records. Built entirely in Python, it allows users to easily input employee data and securely store it in a local JSON file for persistent access. 

This project is perfect for small teams, personal projects, or anyone looking to understand file I/O operations and Object-Oriented Programming in Python.

## ✨ Key Features
* **Data Entry:** Easily add new employees with details including ID, Name, Department, Salary, and Position.
* **Input Validation:** Built-in error handling ensures that salary inputs remain numeric, preventing application crashes.
* **Persistent Storage:** Automatically saves and appends new records to an `employee_data.json` file without overwriting existing data.
* **Data Retrieval:** Instantly read and format all stored employee records directly in the terminal.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Libraries:** `json` (Standard built-in library)
* **Storage:** JSON File System
